# Software Bug Assistant
Triage smarter, fix faster.

## Features

- **Automated Bug Triage**: Uses natural language processing to understand incoming bug reports and categorize them automatically, reducing manual triage effort by 50%.
- **Contextual Analysis**: Aggregates insights from internal ticketing systems (PostgreSQL), GitHub MCP issues, StackOverflow, and Google Search to provide complete debugging context.
- **Root Cause Suggestions**: Leverages Retrieval-Augmented Generation (RAG) and function calling to suggest likely root causes and link related fixes.
- **Priority Automation**: Dynamically updates bug priority based on severity, recurrence, and impact, cutting average response time by 40%.
- **Seamless Integration**: Built with Google ADK and LangChain for smooth interoperability with existing developer workflows.

> “The sooner you find the bug, the faster you can squash it.”

## Techstack

- **Languages & Frameworks**: Python, LangChain
- **AI & Tools**: Google ADK, Retrieval-Augmented Generation (RAG)
- **Database**: PostgreSQL
- **Integrations**: GitHub MCP, StackOverflow, Google Search
